# 단계별 진행 상태

체크는 실제 수행한 범위에만 표시합니다. 코드 구현은 Windows 실기기 완료를 의미하지 않습니다.

## 1단계 · 개발 환경
- [x] 클라우드 Python/Git/Node/Codex 확인, 프로젝트·가상환경 구성
- [x] Windows 설치 스크립트 및 설치 지침
- [ ] 사용자 Windows의 Python/Git/Node/Codex 확인
- [ ] loopMIDI 설치 및 포트 생성
- [ ] Cubase 10.5 테스트 프로젝트와 미디어 백업

## 2단계 · 제어
- [x] MIDI 송신, 매핑 검증, 실측 보간 구현
- [x] 검증되지 않은 매핑 사용 차단
- [ ] Generic Remote 입력 연결 및 트랙별 CC 설정
- [ ] 실제 페이더 제어와 dB 캘리브레이션 확인
- [ ] EQ/컴프레서 Quick Controls 실측 및 연결

## 3단계 · 오디오 분석
