# Auto 승인·적용

승인 토큰을 입력하고 **Auto 켜기**를 누르면 별도의 목록 새로고침·적용 클릭 없이 다음을 반복합니다.

- 기존 및 새 미만료 `pending`: 승인 → 적용
- 기존 및 새 미만료 `approved`: 적용
- 목록 자동 갱신, 처리 후 약 1초 뒤 다음 조회

거절·완료·전송 중·결과 불확실·만료 항목은 자동 처리하지 않습니다. 오류가 나면 Auto를 중지하며 자동 재전송하지 않습니다. 중지하거나 토큰을 변경하면 다음 작업을 시작하지 않지만 이미 진행 중인 전송은 취소하지 못합니다.

브라우저 탭과 로컬 승인 서버를 켜 두어야 합니다. 브라우저가 백그라운드 탭을 절전 처리하면 조회가 지연될 수 있습니다. Auto를 켜는 것은 현재 대기 중인 항목과 이후 생성되는 항목의 승인·적용을 허용하는 동작입니다.

업데이트 후 승인 서버를 다시 실행하고 브라우저에서 Ctrl+F5로 새로고침합니다. 이번 UI 변경만 적용할 때는 Cubase MIDI Remote 드라이버를 교체할 필요가 없습니다.

검증: 대기열의 상태·만료·토큰 검사와 Node 모의 환경의 자동 승인/적용·중지·오류 처리를 통과했습니다. 실제 브라우저/Cubase 통합 동작은 별도 확인이 필요합니다.
